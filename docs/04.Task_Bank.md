# Task Bank

## 1. Назначение документа

Данный документ описывает структуру и принципы формирования **Task Bank** — библиотеки учебных задач, используемой в проекте **Study Recommendation System**.

Task Bank является самостоятельным компонентом архитектуры Study Recommendation System и служит источником задач для Recommendation Engine.

В отличие от таблицы `tasks`, которая используется для хранения задач, входящих в историю обучения, **Task Bank** представляет собой независимую библиотеку упражнений, предназначенную для подбора новых задач при повторении материала.

### Связанные документы

Данный документ описывает структуру и принципы формирования **Task Bank**.

Подробная информация о других компонентах системы приведена в отдельных документах:

- `README.md` — обзор проекта и навигация по репозиторию.
- `System_Design.md` — архитектура системы и модель данных.

- `Project_Roadmap.md` — текущее состояние проекта и направления дальнейшего развития.

## 2. Назначение Task Bank

Task Bank выполняет две основные функции.

Первая — хранение библиотеки задач, классифицированных по единой модели знаний.

Вторая — обеспечение Recommendation Engine новыми заданиями для повторения материала.

Благодаря разделению истории обучения и библиотеки упражнений система может рекомендовать задачи, которые ранее не использовались в процессе обучения.

Таким образом Task Bank является связующим звеном между аналитикой обучения и практическими заданиями.

## 3. Архитектура Task Bank

Task Bank является независимым компонентом общей архитектуры проекта.

```text
dictionary
      │
      ▼
task_bank
      ▲
      │
Recommendation Engine
      ▲
      │
Analytics Layer
```

Task Bank не наполняется автоматически.

Новые задачи добавляются вручную после появления соответствующего паттерна в словаре и проходят классификацию по единой структуре знаний проекта.

Каждая задача связана с одним паттерном через внешний ключ `pattern_id`.

Такое решение обеспечивает единообразную классификацию задач и позволяет Recommendation Engine автоматически подбирать упражнения по результатам анализа обучения.

| Поле | Назначение |
|------|------------|
| `bank_task_code` | Уникальный код задачи |
| `pattern_id` | Связь со словарём знаний |
| `difficulty` | Сложность (1–3) |
| `source` | Источник |
| `title` | Название |
| `task_description` | Условие |
| `solution_outline` | Идея решения |
| `common_mistakes` | Типичные ошибки |

При добавлении новых задач используются следующие принципы:

- одна задача соответствует одному основному паттерну;
- каждый паттерн по возможности представлен задачами трёх уровней сложности;
- условия являются самостоятельными и не требуют дополнительного контекста;
- предпочтение отдаётся задачам, моделирующим реальные рабочие ситуации и технические собеседования;
- банк не содержит намеренных дублей.

В текущей версии проекта используются задачи из различных источников:

- LeetCode;
- DataLemur;
- StrataScratch;
- Interview Questions;
- AI-generated.

При использовании AI задачи рассматриваются как черновые заготовки и постепенно дорабатываются по мере развития проекта.

## 4. Почему Task Bank выделен в отдельную таблицу

При проектировании системы рассматривался вариант хранения всех задач в одной таблице.

Однако такая структура не позволяла разделить уже решённые задачи и упражнения, предназначенные для будущего обучения.

Выделение Task Bank в отдельную сущность позволило:

- независимо расширять библиотеку задач;
- рекомендовать новые упражнения;
- хранить несколько задач одного паттерна;
- постепенно повышать качество банка без изменения истории обучения.

Благодаря этому Recommendation Engine может рекомендовать новые задачи, не изменяя и не используя напрямую историю обучения.

---

## 5. Связь с Recommendation Engine

Task Bank не принимает решений о том, какие задачи необходимо рекомендовать пользователю.

Его задача заключается в хранении библиотеки упражнений, классифицированных по единой модели знаний.

Recommendation Engine анализирует историю обучения, определяет темы и паттерны, требующие повторения, рассчитывает рекомендуемый уровень сложности и только после этого обращается к Task Bank для подбора подходящей задачи.

Таким образом Recommendation Engine отвечает за принятие решений, а Task Bank — за предоставление соответствующих учебных материалов.

Подробная логика формирования рекомендаций приведена в документе **Recommendation_Engine.md**.

## 6. Текущее состояние

Task Bank находится в стадии активного развития.

На текущем этапе Task Bank постепенно расширяется одновременно с развитием словаря паттернов.

После появления нового паттерна в системе для него создаются одна или несколько тренировочных задач различных уровней сложности.

Таким образом библиотека упражнений развивается вместе с накоплением истории обучения и постепенно увеличивает покрытие предметной области.

По мере использования рекомендательной системы планируется постепенно пересматривать формулировки задач, уточнять классификацию паттернов и удалять неудачные или дублирующиеся упражнения.

После завершения ревизии Task Bank станет основным источником задач для Recommendation Engine.

---

## 7. Направления развития

В дальнейшем планируется хранить отдельную историю решений задач из Task Bank в таблице `task_bank_attempts`.

Это позволит:

- отслеживать прогресс по новым задачам;
- исключать уже решённые упражнения из рекомендаций;
- анализировать эффективность повторения;
- учитывать историю решений при выборе следующих задач.

После появления этой таблицы Recommendation Engine сможет учитывать не только историю обучения (`attempts`), но и историю выполнения задач, рекомендованных системой.

Кроме того, планируется:

- завершить покрытие всех паттернов;
- добавить несколько задач каждого уровня сложности;
- учитывать историю выполнения задач банка;
- реализовать интеллектуальный подбор упражнений;
- автоматически исключать недавно решённые задачи;
- использовать банк задач для персонализированного обучения.

После внедрения Knowledge Map Task Bank будет использоваться для оценки покрытия предметной области учебными задачами и поможет выявлять темы, для которых ещё отсутствуют упражнения.
